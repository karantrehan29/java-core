Object-Oriented Principles:

There are four pillars of object-oriented programming:
1. Encapsulation
2. Abstraction
3. Polymorphism
4. Inheritance

Encapsulation: Encapsulation is the bundling of data and the methods that operate on
that data inside a class. It restricts direct access to an object's internal state and
allows access through controlled methods.

e.g.,

public class Payment {

    private int discount = 5;

    public int doPayment(int price1, int price2) {
        int total = price1 + price2;
        total -= total * discount / 100;
        return total;
    }
} 

Abstraction: Abstraction exposes only the essential behavior of an object and hides
the implementation details. The user knows what an operation does, but does not need
to know how it is implemented.

public class Coffee {

    private Ingredients ingredients;

    public Coffee(Ingredients ingredients) {
        this.ingredients = ingredients;
    }

    public void makeCoffee() {
        boilWater();
        addIngredients();
        addMilk();
    }

    private void boilWater() { }

    private void addIngredients() { }

    private void addMilk() { }
}

Inheritance: Inheritance allows a child class to reuse and extend the fields and
methods of a parent class. It represents an "is-a" relationship and helps avoid
duplicating common behavior.

class Animal {

    public void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {

    @Override
    public void sound() {
        bark();
    }

    private void bark() {
        System.out.println("Dog barks");
    }
}


Polymorphism: Polymorphism means "many forms." It allows the same method call or
interface to produce different behavior depending on the object involved.
It has two types:

Compile-time polymorphism: Method overloading, where methods have the same name
but different parameter lists. The compiler decides which method to call.

public class Shape {

    public double area(double length, double breadth) {
        return length * breadth;
    }

    public double area(double radius) {
        return Math.PI * radius * radius;
    }
}

Run-time polymorphism: Method overriding, where a subclass provides its own
implementation of a method inherited from its parent class. The method called is
decided at runtime based on the actual object.
