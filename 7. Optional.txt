Optional

A method may return a value or no value (traditionally represented by null).
Optional<T> represents a value that may or may not be present. It helps you
handle the absence of a value explicitly; it does not catch NullPointerException.

Example:

Optional<String> result = Optional.ofNullable(someObject.method());

if (result.isPresent()) {
    String value = result.get();
    // Use value
}

If someObject itself may be null, calling method() on it can still throw
NullPointerException.
